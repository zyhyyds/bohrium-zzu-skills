# 创新点、方法与价值边界｜15_阅读15_文献知识图谱构建_product-arena-10-760d1a0b

- **新增能力**：跨篇来源隔离 + 逐边证据。脚本给每篇论文独立 `source_id`，候选节点与边都带 `paragraph_id` 与原文短引；`cross_source_conflicts` 专门记录跨篇同形但未必同对象的表面形式。
- **方法改进**：`merge_policy` 要求别名、缩写、同对象证据一致才合并；每条关系限定类型（uses/improves/compare/support/contradict）与方向，禁止把综述转述当直接证据。
- **边界**：三个查询必须由 Agent 在最终图上真实执行；无结果返回空结果加原因，不编造关系。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：实体真实出现率、关系类型/方向准确率、别名归一正确率、节点与边证据覆盖率、查询结果可复核率、跨篇整理耗时。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
