# 创新点、方法与价值边界｜08_写作08_引言与相关工作写作_product-arena-04-4b82ad21

- **新增能力**：论断—引用绑定 + 空白推导链。脚本从材料切出 `claim_table`（含 citations 与 locator）、`gap_candidates` 与 `contribution_candidates`，成稿四部分都要求回指这些结构化候选。
- **方法改进**：`grouping_axis` 固定按问题设定/方法路线/数据与评价方式分组，禁止按时间罗列；写作与核对分离，贡献逐条对齐图表证据。
- **边界**：查不到原文的引用进人工确认，不写成事实；空白缺乏依据时只写可支撑的背景并标 partial。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：转述准确率、分组合理性、空白推导成立率、贡献—证据对齐率、引用覆盖率、成稿返工轮次。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
