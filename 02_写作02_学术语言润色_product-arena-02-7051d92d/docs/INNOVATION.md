# 创新点、方法与价值边界｜02_写作02_学术语言润色_product-arena-02-7051d92d

- **新增能力**：最小编辑 + 限定强度守恒。脚本把风险表达（冗余、绝对化、中式英语、冠词重复）列成 `polish_worklist`，`invariant_report` 同时比对数字、引用、限定词、强化词与弱化词。
- **方法改进**：强制"原文—改文—类型—理由"四元组，并把 `strengtheners_added` / `weakeners_removed` 作为独立信号，专门防止润色偷偷加强或削弱结论。
- **边界**：不整段重写，不修改数据与引用编号；目标期刊风格、专业译名等进 `needs_human_confirmation`。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：语法硬错误修正率、术语一致率、限定强度守恒率、数据/引用/图表指向守恒率、逐句说明完整率、返修轮次。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
