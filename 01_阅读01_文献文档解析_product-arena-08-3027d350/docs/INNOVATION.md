# 创新点、方法与价值边界｜01_阅读01_文献文档解析_product-arena-08-3027d350

- **新增能力**：块级锚点解析 + 版式问题单点攻坚。脚本先把输入切成带 `block_id` 的块并给出标题/题注/表格序列，Agent 只需针对选定的一种版式问题（串栏、跨页表、章节树、公式符号或 OCR）做人工校正，避免"全文重读一遍"的低效循环。
- **方法改进**：`structure_summary` 与 `order_checks` 把"提得全、排得对、拆得清、核得回"四个评分点变成可逐项勾选的确定性检查；PDF 无文字层时强制走 pdf-text-tool / pdf-render-tool / ocr-tool 并写 `uncertainty`，不允许猜测补字。
- **边界**：脚本不替代真实 PDF 读取，也不解释公式与图表的科学含义；增益来自锚点化与单一版式攻坚，而不是宣称通用 PDF 解析器。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：逐字提取完整率、阅读顺序正确率、表格行列归属准确率、公式符号保真率、锚点可回查率、人工校对耗时。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
