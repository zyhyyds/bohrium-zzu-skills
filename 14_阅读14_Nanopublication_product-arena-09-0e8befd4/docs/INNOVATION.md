# 创新点、方法与价值边界｜14_阅读14_Nanopublication_product-arena-09-0e8befd4

- **新增能力**：断言粒度判据 + 最小充分证据判据。脚本按并列/转折连接词切出候选，再由 Agent 按"一个主体、一个关系、保留限定条件"继续拆；每条断言必须绑定连续原文短引与 source_id。
- **方法改进**：`quality_rules` 把断言过宽、证据不足、主体混淆、关系方向错误、来源缺失列成可复现判定；`export_schema` 固定序列化字段，下游无需人工清洗。
- **边界**：找不到支撑的断言保留为 unsupported 而不是删改；间接推论标 indirect，不把共现当因果。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：断言原子化粒度、主体/关系方向准确率、最小充分证据命中率、来源元数据完整率、导出可直接解析率、人工拆分耗时。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
