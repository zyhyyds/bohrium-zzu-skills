# 创新点、方法与价值边界｜04_写作04_参考文献与引用管理_product-arena-03-429cc14d

- **新增能力**：编号连锁更新 + 去重判据分层。脚本一次算出 `numbering_map`、`missing_entries`、`unused_entries`、`numbering_gaps` 与 `duplicates`，判据优先级为 DOI > 归一化题名，避免同名作者误合并。
- **方法改进**：把"挂得对、编得顺、收得净、对得上"拆成可核验证据；每条引用点带 file+line 锚点，合并决策保留 basis，正文与文末双向同步有据可查。
- **边界**：DOI 无法解析标 unknown，不伪造条目；论断与文献主题是否匹配由 Agent 逐句判断并留证据。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：引用位置准确率、编号连续与同步率、去重判据可解释率、元数据准确率、论断—引用匹配率、逐条核对耗时。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
