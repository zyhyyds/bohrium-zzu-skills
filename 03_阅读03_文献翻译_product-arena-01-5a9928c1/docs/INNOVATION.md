# 创新点、方法与价值边界｜03_阅读03_文献翻译_product-arena-01-5a9928c1

- **新增能力**：术语表强制回填 + 段号守恒。脚本抽出的 `glossary_candidates` 带 `fixed_by_skill` 标记，`segments` 带稳定段号；Agent 必须回填译名并逐段给出 anchor，才能通过自检闸门。
- **方法改进**：`invariant_report` 把数字、单位、引用标记、限定词做成自动生成的前后差异清单；术语回扫与段号检查把"术语稳、段落全、关系准、可核验"变成可机器判定的动作，而不是写在提示词里的口号。
- **边界**：不生产预写译文，不解释图片内公式；无法读取的部分进 `needs_human_confirmation`。增益来自术语锁定与守恒核对，不宣称通用机器翻译质量。

## 与基线对照的设计

平台以同一案例分别运行基础 Agent 与加载本 Skill 的 Agent。本 Skill 的可观察增量集中在：术语一致率、段落完整率、段号对应关系、数字/单位/引用守恒率、逐段可回查率、人工校对耗时。

增益不是靠文字自述，而是靠 `verification.json` 的确定性检查与 `comparison.json` 中逐项指向真实产物的证据。评审可用同一输入重跑 `scripts/solve.py` 复核这些信号。

## 可复用边界

本 Skill 聚焦一种明确任务，不声称是通用系统；换学科、换文体时需替换术语表/风格规则/字段模板，但锚点、守恒与审计机制保持不变。
